## Cómo se usa

1. **Selecciona el firmware**

   Abre el host que corresponda a la versión de firmware de tu consola.

2. **Carga el exploit**

   Una vez dentro del host, ejecuta el exploit y espera a que finalice el proceso.

3. **Si la consola presenta algún tipo de cuelgue**

   Reinicia o apaga la consola.

4. **Vuelve a intentarlo**

   Enciende nuevamente la consola y repite el proceso desde el principio.

5. **Prueba otro host**

   Si el problema persiste, prueba con otro host compatible con tu versión de firmware.
