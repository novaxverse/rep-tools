# NovaXverse · Repositorio de Instaladores

Página de descargas de NovaXverse con herramientas, homebrew y utilidades para PS4. Cada tarjeta enlaza directamente a su archivo `.pkg`.

## Cómo descargar e instalar

1. En el navegador de tu consola liberada, ingresa el enlace de esta página.
2. Elige el archivo que quieras y pulsa **Descargar**.
3. Cuando termine la descarga, instala el `.pkg` a través de **GoldHEN**.
