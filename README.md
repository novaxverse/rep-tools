## Cómo se usa

1. Abre la página desde el navegador de la PS4 (o cualquier dispositivo).
2. Pulsa el host que corresponda a tu firmware para cargar el exploit.

## Publicar en GitHub Pages

1. Sube estos archivos a la raíz de un repositorio de GitHub (o al repositorio `TU-USUARIO.github.io`):
   - `index.html`
   - `style.css`
   - `banner.png`
   - `candado-abierto.png`
   - `notification.png`
2. En el repositorio: **Settings → Pages → Source: Deploy from a branch → Main (root)**.
3. Tu página queda en `https://TU-USUARIO.github.io/TU-REPOSITORIO/`.
